GRAVIT — LOADING SPINNERS
=========================

Four animated SVG loaders, each built on the Gravit "G" mark.
Animation is native SMIL — loops on its own, no CSS/JS required.

Files
-----
gravit-spinner-F3-draw-erase.svg      G draws on, then erases off
gravit-spinner-G1-outer-ring.svg      static G inside one sweeping ring
gravit-spinner-G2-dual-ring.svg       two counter-rotating rings around the G
gravit-spinner-G3-breathing-ring.svg  ring grows/shrinks while rotating

Colors
------
Accent gradient  #8B7CF6 -> #4EA8FF   (violet -> blue)
Transparent background — sits on any dark surface.

Usage
-----
Inline the <svg> or reference it:
  <img src="gravit-spinner-G2-dual-ring.svg" alt="Loading" width="120" height="120">

Note: SMIL animation runs when inlined or via <img>, but NOT when used as a
CSS background-image. Ask if you need a CSS-keyframe version instead.
